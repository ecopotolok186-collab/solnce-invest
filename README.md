# SOLNCE INVEST

Мобильный инвестиционный калькулятор «Солнце Дизайн»: пример условий частного финансирования на 36 месяцев.

Статическое PWA без сервера, сборки, регистрации, аналитики и хранения данных. Все вычисления выполняются в браузере.

## Файлы

| Файл | Назначение |
|---|---|
| `calc.js` | Финансовая модель и XIRR |
| `app.js` | Логика интерфейса |
| `index.html`, `styles.css` | Разметка и оформление по брендбуку |
| `sw.js`, `manifest.webmanifest` | PWA и работа без интернета |
| `tests/` | Тесты расчётов |

## Как изменить условия

Эталонные платежи находятся в начале `calc.js`, в массиве `PERIODS`. Совокупный возврат задан в функции `calculate` (`amount * 17 / 10`). При изменении условий обновите тексты про 70% в `index.html` и `calc.js`, а также ожидаемые значения в `tests/`.

## Проверка

```bash
node --test tests/calc.test.js
python3 tests/verify_independent.py
```

## Публикация

Сайт раздаётся через GitHub Pages из ветки `main`, папка `/` (root). Любой коммит в `main` публикуется автоматически примерно за минуту. Service worker сначала обращается к сети, поэтому посетители с интернетом получают новую версию при следующем открытии.
